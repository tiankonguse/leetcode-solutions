给你一个整数数组 `nums` 。

每个 `nums[i]` 都是一个 **编码后的** 整数，表示两个正整数 `x<sub>i</sub>` 和 `y<sub>i</sub>` 。要解码 `nums[i]` ，定义：

- `width<sub>i</sub> = nums[i] % 10` 。
- `d<sub>i</sub> = floor(nums[i] / 10)` 。
- `x<sub>i</sub>` 为由 `d<sub>i</sub>` 的十进制表示中前 `width<sub>i</sub>` 位数字组成的整数。
- `y<sub>i</sub>` 为由 `d<sub>i</sub>` 的十进制表示中剩余所有数字组成的整数。

保证 `d<sub>i</sub>` 的十进制表示包含的数字位数大于 `width<sub>i</sub>` 。因此， `x<sub>i</sub>` 和 `y<sub>i</sub>` 都至少包含一位数字。

`nums[i]` 的 **解码值** 为 `x<sub>i</sub><sup>y<sub>i</sub></sup>` 。

返回 `nums` 中所有元素的解码值之和，并对 `10<sup>9</sup> + 7` 取模。

`floor()` 函数返回除法结果的整数部分。

**示例 1：**

**输入：** nums = \[231\]

**输出：** 8

**解释：**

- 对于 231，有 `width = 1` 、 `d = 23` 、 `x = 2` 、 `y = 3` 。
- 231 的解码值为 `2<sup>3</sup> = 8` 。
- 由于 `nums` 中只有一个元素，因此所有解码值之和为 8。

**示例 2：**

**输入：** nums = \[2522,2101\]

**输出：** 1649

**解释：**

- 对于 2522，有 `width = 2` 、 `d = 252` 、 `x = 25` 、 `y = 2` 。
- 2522 的解码值为 `25<sup>2</sup> = 625` 。
- 对于 2101，有 `width = 1` 、 `d = 210` 、 `x = 2` 、 `y = 10` 。
- 2101 的解码值为 `2<sup>10</sup> = 1024` 。
- 所有解码值之和为 `625 + 1024 = 1649` 。

**示例 3：**

**输入：** nums = \[2301\]

**输出：** 73741817

**解释：**

- 对于 2301，有 `width = 1` 、 `d = 230` 、 `x = 2` 、 `y = 30` 。
- 其解码值为 `2<sup>30</sup> = 1073741824` 。
- 因此，答案为 `1073741824 modulo (10<sup>9</sup> + 7) = 73741817` 。

**提示：**

- `1 <= nums.length <= 10<sup>5</sup>`
- `100 < nums[i] < 10<sup>15</sup>`
- `1 <= width<sub>i</sub> <= 9`
- `1 <= x<sub>i</sub>, y<sub>i</sub> < 10<sup>9</sup>`
- 用于构成 `x<sub>i</sub>` 和 `y<sub>i</sub>` 的数字序列均不包含前导零。
- 保证 `nums` 中的每个元素都是有效的编码整数。
