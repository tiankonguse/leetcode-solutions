
[Q2. 至多 K 次数字重排后的最大和](https://leetcode.cn/contest/weekly-contest-525/problems/maximize-sum-after-at-most-k-digit-rearrangements/)

给你一个长度为 `n` 的整数数组 `nums` 和一个整数 `k` 。

在一次操作中，你可以选择 `nums` 中的任意一个元素，并以任意顺序 **重新排列** 其十进制数字，组成一个新的整数。

返回在执行 **至多** `k` 次操作后，数组元素之和的 **最大值** 。

**示例 1：**

**输入：** nums = \[123,45\], k = 1

**输出：** 366

**解释：**

- 选择 `nums[0] = 123` ，重新排列其数字，得到 321。
- 数组变为 `[321, 45]` 。因此，元素之和为 `321 + 45 = 366` 。

**示例 2：**

**输入：** nums = \[102,90,14\], k = 2

**输出：** 341

**解释：**

- 选择 `nums[0] = 102` ，重新排列其数字，得到 210。
- 选择 `nums[2] = 14` ，重新排列其数字，得到 41。
- 数组变为 `[210, 90, 41]` 。因此，元素之和为 `210 + 90 + 41 = 341` 。

**提示：**

1 <= n == nums.length <= 10^5
1 <= nums[i] <= 10^9
1 <= k <= n
