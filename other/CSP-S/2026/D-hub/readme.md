## 分析

首先是理解题意。
题目希望选择 k 个点，这些点形成的图不超过两个连通块。  
求其余点到这个连通块的最大距离最小。  



![](https://res2026.tiankonguse.com/images/2026/11/09/001.png)


最大中秋最小，显然需要二分答案。  
二分最大距离 R，判断是否满足形成的图不超过两个连通块。  


![](https://res2026.tiankonguse.com/images/2026/11/09/002.png)



定义1：距离叶子节点的最大距离为高度。  
PS: 也可以反向定义剩余删除次数。


![](https://res2026.tiankonguse.com/images/2026/11/09/003.png)



显然，高度小于 R 的节点，都不需要选择的。  
因为只需要选择高度大于或等于 R 的节点，高度小于 R 的节点可以在 R 距离内到达连通块。  
这个就需要进行删除所有高度小于 R 的节点。  



![](https://res2026.tiankonguse.com/images/2026/11/09/004.png)



对于剩余的点，要么组成一个连通块，要么是两个连通块。  
如果是一个，需要满足剩余的点的个数不超过 K，可以 `O(1)` 得到判断。  
如果剩余的点的个数大于 K，则只能拆分为两个连通块。  



由于已经删除了高度小于 R 的节点，这两个连通块肯定是被一条链分割。  
可以反证法证明。  

![](https://res2026.tiankonguse.com/images/2026/11/09/005.png)



此时，问题就转化为了，给若干个数字，需要选择一个定长的区间，区间上每个点，需要满足到左右某个端点的距离不超过指定值，问是否存在这样的区间。  
暴力做法是枚举，复杂度 `O(n^2)`  
所以，肯定存在一个线性的算法，可以在 `O(n)`内完成判断。  


这样，整体复杂度就是 `O(n log(n))`。  


## 如何删点  


现在第一个问题是如何删点。  
最常见的做法是找一个根，然后 DFS。  
为了能够判断一个点是否可以删除，显然需要计算出每个节点的高度，从而可以判断。    


![](https://res2026.tiankonguse.com/images/2026/11/09/006.png)



但是这样会有一个问题：根节点自身可能需要进行删除。  


所以，还需要再换一个节点来当做根，再 DFS 删除一次。  


选择哪个点呢？  
前面提到，高度小于 R的节点都删除了，那高度为 R 的节点肯定不能删除。  
故，第一次 DFS 的时候，顺便记录一个高度为 R 的节点，然后再以这个点为根，重新 DFS 删除一轮即可。  


![](https://res2026.tiankonguse.com/images/2026/11/09/007.png)


## 如何枚举链


对于一个链，边界要么是叶子，要么是度大于2的节点。  
所以直接从一个叶子节点当做根，遇到一个顶点是度数大于2的节点了，枚举所有边，需要边的另一个端点度数为2，则找到一条链的起点，不断循环就可得到这个链的所有点。  


注意，这里复杂度不是 `O(n^2)`的，而是均摊 `O(n)`的。  
因为每个边只会属于一个链，我们只会枚举一次。  


![](https://res2026.tiankonguse.com/images/2026/11/09/008.png)


## 暴力判断链是否满足条件


假设缩点后剩余 A 个点，链的长度为 B 个点。  
则可以推导出，链之外有 `A - B` 个点。  


题目要求连通块最多选择 K 个点，如果 `A-B > K`，那显然这个链不满足，可以剪枝掉。  



满足之后，可以计算出这个链可以选择 `M = K - (A-B)`个点。  


为了保证有两个连通块，链上选择的点必须是两端连续的点。  
也就是说，链中间有一个长度为 `A - K` 的点不能选择，其他的都需要选择。  



如下图，每个点有自己的一个高度，即已经从分叉上删除了若干点。  
需要满足所有点到达来两端的高度不大于 R。  


![](https://res2026.tiankonguse.com/images/2026/11/09/009.png)


当存在一个区间满足时，就存在答案。  
区间从左滑动到右侧，共 B 种区间，每种区间都需要枚举区间内的点，复杂度`O(B^2)`  
所有链合起来，综合复杂度不大于 `O(n^2)`  


故，这道题的复杂度就是 `O(n^2 log(n))`  
得分：80 分
代码： hub-v1-80-TLE.cpp


## 滑动窗口


暴力做法是固定区间后，枚举区间内的点，判断是否可以到达区间的两端。  
其实可以反过来看，判断两个端点可以覆盖的最远点，如果可以把整个区间覆盖，则存在答案。  


如下图，分三种情况。  
1）左端点向右，右端点向左，最远点有交叉，那显然所有点都可以被覆盖到。  
2）最远点相邻，那所有点还是可以被覆盖到的。  
3）有某些点都未到达，则这些点不满足要求，这个区间不能得到答案。  


![](https://res2026.tiankonguse.com/images/2026/11/09/010.png)



假设左端点 `l` 最远可以覆盖到 `right[l]`。  
则显然，对于 `l+1`，肯定可以覆盖到 `right[l]`，至于再往后，由于还没到达过，不知道。  


所以，可以使用滑动窗口，复用前面一个位置的信息，快速计算出所有左端点的最远距离，复杂度 `O(n)`。  

同理，也可以计算出右端点向左的最远距离。  


最后，枚举所有区间，判断左右端点的最远距离是否可以覆盖所有点。  


一次判断中，复杂度始终都是 `O(n)`  


综合复杂度：`O(n log(n))`  
得分：80 分  
代码：hub-v2-80-TLE.cpp
PS：哭死，复杂度少了一个 n，竟然还是 80 分。

输入换成 fastRead。

剪枝2：第二个DFS删点后，就满足1个联调块，返回有答案。

## 满分优化  


观察代码，由于存在删点，随意我们把图复制了一遍，这里有一个 `O(n)`。  
另外为了删除点，使用了两次 DFS，这里是两个 `O(n)`。  
最后枚举链，又是一个 `O(n)`。  


那这里是否可以不把图复制一遍呢？  
只所以复制图，是为了删点。  


只所以要真实删点，是因为点与最远叶子的关系，定义的是剩余删除次数。  
随着 R 的变化，剩余删除次数也都在变化。  


如果把点与叶子最远叶子的关系，定义为到叶子的高度。  
则不管 R 如何变化，高度是永远不变的。  


![](https://res2026.tiankonguse.com/images/2026/11/09/003.png)



由于高度不随 R 变化，所以可以预处理一次计算好。  


```cpp
queue<int> q;
  deg.resize(n + 1, 0);
  maxDis.resize(n + 1, 0);
  for (int u = 1; u <= n; u++) {
    deg[u] = g[u].size();
    if (deg[u] == 1) {
      maxDis[u] = 1;
      q.push(u);
    }
  }
while (!q.empty()) {
  const int u = q.front();
  q.pop();
  for (int v : g[u]) {
    deg[v]--;
    if (deg[v] == 1) {
      maxDis[v] = maxDis[u] + 1;
      q.push(v);
    }
  }
}
```


此时如何删除点呢？  
可以发现，根本不需要删除点了，高度小于 R 的就算删除了，使用的使用判断一下点是否删除即可。  


第二个问题：如何统计删除了多少个点呢？  
循环一遍，统计高度小于 R 的点的个数。  


```cpp
leftNode = n;
for (int i = 1; i <= n; i++) {
  if (maxDis[i] <= R) {
    leftNode--;
  }
}
```


第三个问题：删除点后，节点的度数发生了变化。  
所以，需要循环一遍，计算未删除节点的度。  


```cpp
// 重新计算每个节点的度数
for (int u = 1; u <= n; u++) {
  deg[u] = 0;
  if (maxDis[u] <= R) continue;
  for (int v : g[u]) {
    if (maxDis[v] > R) {
      deg[u]++;
    }
  }
}
```


第四个问题：DFS 需要调用很多次函数，很消耗时间。  
所以，需要消除递归函数。  
枚举链的时候，循环所有点判断是不是链的一个端点，是了，构造链，进行判断。  


```cpp
for (int u = 1; u <= n; u++) {
  if (deg[u] <= 0 || deg[u] == 2) continue;
  for (int v : g[u]) {
    if (deg[v] != 2) continue;  // 链上必须有节点
    if (CheckSplit(v, u)) {
      return true;
    }
  }
}
```

这些优化叠加在一起，最终就可以拿到100分了。  
参考代码：hub-v5-100.cpp
