分析：答案求最大值，数据范围又是 `5e5`，显然需要 `n log(n)`的解法或者更快的解法。  


假设最终相同的能量值是第 R 个水晶，值为 `nums[R]`。  
显然，每次操作都需要优先选择小于等于且最接近 `nums[i]` 的水晶，不断加一，直到把对应的能量值增加到 `nums[R]`。  


怎么找到小于等于且最接近 `nums[i]` 的水晶？
预处理水晶，排序后，上一个水晶就是小于等于且最接近 `nums[i]` 的水晶。



故，可以得到最朴素的解法：
对于每个右边界 `R`，从大到小枚举左边界 `L`，不断判断值都增加到 `nums[R]` 是否超过 m。  
复杂度：`O(n^2)`  
得分：50 分
前 9 组测试点 `n ≤ 5000` 可以轻松通过；
参考代码: crysta-50-v0-TLE.cpp



第 10~12 组测试用例，值域不超过 100。  
这意味着有很多相同值。  


如果最终能量值为 `nums[R]`，显然，所有值为 `nums[R]`的水晶都需要选择。  
即，对于相同值，只需要枚举最后一个位置。  


所以枚举右端点时，增加下面的去重优化即可。  


```cpp
 if (i + 1 < n && nums[i] == nums[i + 1]) continue;
```

复杂度：`O(100 * n)`  
得分: 80 分
前 13 组测试数据全部通过，最后 18~20 三组测试数据竟然也通过了。  
参考代码: crysta-80-v1-property-10-13.cpp



另外，右端点确定后，一个个往前计算时，也可以增加去重优化。  
这个需要先预处理出每个值第一次出现的位置 `unordered_map<ll, int> firstPos`。  


枚举一个 `L` 时，根据当前值的个数，可以计算是否可以全部覆盖。  
能全部覆盖了，一下就把这些位置全部处理了。  
不能全部覆盖了，再往前面的就都无法覆盖，结束判断。
复杂度：`O(diff^2)` 去重后平方的复杂度
得分： 80 分  
参考代码: crysta-80-v2-merge-same.cpp


接下来是性质A 的第 13~15 组测试数据。  
性质A 说所有数字连续递增。  


确定右端点时，第一个数字增加0，第二个数字增加1，第三个数字增加2，依次递推。  
现在总共增加 m, 可以解方程 `(0 + x) * (x+1) / 2 <= m`，直接计算出 `L=R-x`。  
复杂度：`O(n)`  
得分： 90 分  
前 15 组与 18~20 测试数据全部通过。
参考代码: crysta-90-v2-property-A.cpp




再来看性质 A，数字连续递增，而我们不关心具体值，只关心与枚举值的相对值。  
所有枚举值起始位置都是 0 开始的，只是越往后，`R-L` 会越大。  
那显然，枚举到最后一个位置时，`R-L` 最大。  
故，直接计算最后一个位置的答案。  
复杂度：`O(1)`  
得分： 90 分  
参考代码: crysta-90-v3-property-A.cpp


接下来是性质B 的第 16~17 组测试数据。  
性质B 说所有数字形成等差数列。  


根据性质A的解法，可以直接套用，只不过方程更复杂一些而已。  
方程：`(0+xd) * (1+x) / 2 <= m`  
复杂度：`O(1)`  
得分： 95 分  
参考代码： crysta-95-v4-property-B.cpp


为啥会有一组样例没通过吗？  
分析数据范围，发现 m 和 值域太大了，超过了 int64，导致精度问题。
这时候，就不能解方程了，而需要使用二分求方程的解。  
复杂度：`O(log(n))`  
得分： 100 分  
参考代码: crysta-100-v5-property-B.cpp




对于第 R 个水晶，假设最多可以修改到第 `L` 个水晶。  
既然解方程可以二分，那普通情况，是否可以二分查找左边界 `L`呢？  
可以发现，对于 `[0, L)` 都是不满足条件的，对于 `[L,R]` 都是满足条件的，满足单调性。
故可以二分快速找到边界 `L`。  



那对于一个位置 `L`，如何快速判断是否满足呢？  



其实，如果你会前缀和的话，可以利用前缀和，快速判断 `[L,R]` 区间内是否满足条件。
复杂度：`O(n log(n))`  
得分：100 分
参考代码：crysta-100-v6-binary-search.cpp  
  


继续分析对于每个 R，L 的规律，可以发现，L 是单调非递减的。  
故，可以使用一个左边界游标，复用上次的左边界，从而快速找到当前的左边界 `L`。
这种做法，一般称为双指针。  
复杂度：`O(n)`
参考代码： crysta-100-v7-two-point.cpp
