分析:


题目是问有多少个二元组，其最短路的不同路径恰好有 2 个。


最简单的做法是求出所有二元组的最短路与不同路径个数，然后判断是否等于 2。


状态定义：`dpStep[l][r]` 节点 l 到节点 r 的最短路值；
`dpPath[l][r]` 节点 l 到节点 r 的不同路径个数。


状态转移方程：枚举 r 的上一跳节点 k，判断先从 l 若干次到 k，再从 k 直接到 r 是否更优。  
复杂度：`O(n^3)`
得分：24分  
代码: migrate-24-v1-TLE-n3.cpp



分析所有的最短路 `dpStep[l][k]`，可以发现，k 越大，最短路条数就越大。  
即 `dpStep[l][k]` 的最短路满足单调非递减的性质。  


我们目标是找到最小的 `dpStep[l][k]` 最短路，那显然 r 向左能跳到的最小 k 就是答案。  
那怎么快速找到这个最小 k 呢？  
显然可以二分找到，记作 minKFirst。  


另外需要注意，由于是单调非递减，与 `dpStep[l][minKFirst]` 相等的 k 可能不止一个。
所以还需要另外一个二分，找到与 `dpStep[l][minKFirst]` 相等的 k 的右边界，记作 minKLast。  


有了左右边界，路径数就是 `dpPath[l][minKFirst]` 到 `dpPath[l][minKLast]` 的和。  
这就要求维护一个前缀和，来快速计算区间和。  
复杂度：`O(n^2 log(n))`  
得分：24分  
代码: migrate-24-v2-TLE-n2-logn.cpp




分析上面的二分，发现 r 固定时，随着 l 的减少，minKFirst 只会越来越小，而且一旦不再变化，之后就永远不会变化了。
既然这样，可以使用双指针来代替二分。  
PS：再次遇到单调性，可以通过双指针来代替二分。


而对于 minKLast，含义是与 `dpStep[l][minKFirst]` 相等的 k 的右边界。  
随着 l 的减少，`dpStep[l][minKFirst]` 的值会不变或者变大。  
此时，minKLast 是没有规律的，可能变大，也可能变小。  
所以，两个二分只消除一个，还剩下一个二分。  
复杂度依旧是 `O(n^2 log(n))`
得分：24分 
代码: migrate-24-v3-TLE-n2-logn.cpp



继续分析，我们其实只需要判断 dpPath 是否等于 2。  
这意味着，大于 3 的都不可能等于 2。  
也就是会说，`[minKFirst,minKLast]` 大于等于 3 个时，肯定也是没答案的。  
基于此，就可以把另外一个二分消除掉了。  
复杂度：`O(n^2)`  
得分：40分， 5000 以内的数据量都通过了  
代码: migrate-40-v4-TLE-n2.cpp


上面的状态是固定右端点 r，枚举左端点 l。  
其实也可以固定左端点 l，枚举右端点 r。  
复杂度不变
得分：40分

分析性质 A，数据构成等差数列。
等差数列有一个性质，就是任意两个相邻的元素的差值都是相等的。  
所以，如果区间 `[l,r]` 是答案，那 `[l+k,r+k]` 肯定也都是答案。  


分析答案，只有一种情况，才会只有两条路径。  
假设答案是 `[l,r]`，那么 `[r-d,l+d]` 内恰好只有两个点。


总结下这个规律，即存在四个点，两边的距离不大于 2*d，且`[r-d,l+d]` 内恰好只有两个点。
这个性质很重要，所有答案都满足这个性质。  


判断等差数列是否满足这个规律，满足了，有答案，统计答案的个数。  
复杂度：`O(1)`  
得分：48分  
代码: migrate-48-v6-TLE-A.cpp


性质B是存在一座岛屿，使得海鸟可以从该岛屿直接飞到任意其他岛屿。  
这意味着，xn - x1 <= 2*d。  


结合性质A得到的结论，可以确定，如果存在答案，那么只能选择三个点。  
枚举所有左端点 `l`，找到最大步长 d，假设可以覆盖的最后三个点，记作 l1,l2,l3，满足 `l1 <= l2 <= l3`。  
右端点 `r` 必须满足 `l1 < r-d <= l2`,即 l3 只能覆盖 l2和l3，不能覆盖 了。  
二分查找出所有满足条件的 r，就是答案。
复杂度：`O(n log(n))`
得分：56分  
代码: migrate-56-v7-TLE-B.cpp

基于性质A和性质 B，其实已经可以推导出正确算法了。  


性质A 推导出了， `[r-d,l+d]` 内恰好只有两个点时才会有2条路径。  
性质B 推导出了 l 和 两个点确定后，可以计算出有多少个 r 端点。  


两个结合，枚举两个相邻点，则可以根据性质 B 推导出有多少个满足条件的 r，个数记作 `R0n`。  
同理，也可以推导出有多少个满足条件的 l，记作 `L0n`。  
左右互相独立，答案是两边个数的乘积就是所有长度为 3 的路径数。



接下来看长度为 4 的路径的特征。  


由于左右对称性，假设左侧固定为 l，覆盖的两个点固定时 l2 和 l3，根据性质 A ，我们已经只有多个 r 可以构成长度为 3 的满足条件的路径。  
那这些 r 中，有哪些可以再向右加一条边呢？  


由于前面已经构造了两个路径了，接下来加的边的路径必须是唯一的。  


画图可以发现，只有最远的那个 r 才能构造出唯一的路径。  
其他的 r 加一条边后，路径数就不是 2 条，而是至少 4 条了。  


由此，可以得到一个性质D：对于长度大于 3 的路径，除了三个相邻顶点有两条路径外，其他的路径在中间都是唯一的，且必须取最长的那一跳。  


选择最长的那个顶点 r 后，剩下的最后一个顶点 `r1` 可以选择哪些呢？  
显然，为了满足不能构造出第二条路径的条件， R-d 只能覆盖 r，不能覆盖 r 之前的点，否则就可以选择又多出两个路径。  
根据这个条件，即可算出有多少个 `r1` 满足条件，记作 `R1n`。  


由此递推，右侧如果需要再加一条边，就连续两次选择最长的那一跳，然后最后一跳满足 `R-d` 只覆盖最后一个点。  
右侧所有满足条件的路径如下：  


```
0 跳：R0n
1 跳：R1n
2 跳: R2n
...
```

故，右侧的路径总数是 `R0n + R1n + R2n`。  
可以预处理后缀和，从而知道某个点右侧共有多少个唯一的路径数。  


同理，也可以计算出左侧的总路径数 `L0n + L1n + ...`。  
两边相乘，即可得到所有路径数为 2 的答案。  


如何找到能够覆盖多少个点呢？  
如果使用二分，复杂度就是 `n log(n)`
参考代码：migrate-100-v8-n-logn.cpp  
得分：100 分


如果使用双指针预处理出每个点左右 d 范围内的最后一个点，则可以 `O(1)`的计算出答案。  
复杂度：`O(n)`  
参考代码：migrate-100-v9-n.cpp
得分：100 分
